# Email Service

Este microservicio se encarga del **envío de correos electrónicos** del sistema.  
Permite enviar notificaciones, confirmaciones de registro y alertas automatizadas.

## Funcionalidades principales
- Envío de correos de bienvenida
- Envío de notificaciones del blog
- Integración con servicios de correo externos (por ejemplo, SendGrid o Mailgun)
