# Reverse Proxy

Este servicio actúa como **puerta de entrada (gateway)** del sistema.  
Gestiona el enrutamiento del tráfico a los distintos microservicios y mejora la seguridad y escalabilidad.

## Funcionalidades principales
- Balanceo de carga
- Redirección de peticiones a los microservicios
- Implementación de políticas de seguridad (CORS, HTTPS, rate limiting)
